# エディタの音声入力（書き起こし＋校正）の方式調査

issue: #323 / 調べた日: 2026-10-13 / コードは変えていない（調査のみ）

## 結論

**まず B（録音して API に送り、Cloudflare Workers AI の Whisper で書き起こす）から始め、校正（C）は第2段にする。** A は日本語の対応が足りず、D は今の Claude が音声を受けられないため選べない。

- B（Workers AI）が合う理由
  - 費用が最も小さい。1,500 分/月（下の前提）でも約 $0.77、無料枠（毎日 10,000 Neurons）に収まれば $0
  - 外部の鍵が要らない。Worker の `AI` バインディングで呼べるので、「外部 AI の鍵を置く場所」の問題が起きない
  - 音声は Cloudflare の中で完結し、新しい事業者へ音声を渡さない
- 校正（C）は、Claude Haiku 5.5 なら月 $0.5 前後で足せる。ただし「言っていないことが入る」害があるので、直す前の文を残して選べる形にしてからにする
- A（ブラウザの音声認識）は、費用 0 だが Firefox が既定で無効、Edge は対応なし、Chrome は音声が Google に送られる。管理画面の使う人のブラウザを選べないので、土台にしない

## 範囲をこう読んだ

issue の「調べる」の3点（方式の比較、見積もり、鍵の置き場所）と「決めること」を、判断を求める形に並べる。実装には進まない。管理画面の人数と使う量は issue に無いので、下の前提を仮に置いた（変えたら表の数字は掛け算で直せる）。

### 各方式の根拠

- **A**: caniuse では Chrome 25 以降と Safari 14.1 以降（iOS は 14.5 以降）が「部分的な対応」、Firefox は「既定で無効」、Edge（79 以降）は非対応。MDN は、Chrome のように「音声がウェブサービスへ送られ、オフラインでは動かない」ブラウザがあると書く
- **B**: Workers AI の料金は `@cf/openai/whisper-large-v3-turbo` が 1 分 $0.0005（46.63 Neurons）、無料枠は全モデル合わせて毎日 10,000 Neurons（UTC 0 時に戻る）、超えた分は 1,000 Neurons あたり $0.011。無料枠は約 214 分/日（取得した表からの計算）。入力は音声の base64、またはオブジェクト（`body` と `contentType`）で、大きさの上限は公式ページに書かれておらず、確かめられなかった
- **B'**: OpenAI の料金表で、gpt-4o-transcribe が 1 分あたり約 $0.006、gpt-4o-mini-transcribe が約 $0.003、Whisper が $0.006（gpt-4o 系の 1 分の額は、トークン課金からの推定値と表に明記されている）
- **C**: Claude の最新の価格は、Claude API の公式の表（取得日 2026-10-06 の写し）で、Haiku 5.5 が入力 $0.10 / 出力 $0.50（100K トークンまで。超えると $0.50 / $2.50）、Sonnet 5.5 が $2 / $10（1M トークンあたり）
- **D**: Claude の機能一覧には音声入力の項目が無く、Messages API の入力は文字と画像（と PDF）。Anthropic 自身の音声アシスタントの例も、書き起こしは別のサービス（ElevenLabs）に任せている。リリースノートの確認は 2026 年 5 月分までで、それ以降に音声対応が入っていないかは確かめられなかった。使う時点でもう一度確かめる

## 費用の前提

利用量は仮置き。issue にある「1日10分 × 30日」を 1 人ぶんとし、使う人は 5 人とする。

- 1 人 300 分/月 × 5 人 = **1,500 分/月**（Workers AI の無料枠は約 6,420 分/月ぶん）
- 校正の長さ: 10 分の発話 ≒ 日本語 3,000 字 ≒ 4,500 トークン（入力）、校正後も同じくらい（出力）と**見積もった**。実測していない
- 校正は 10 分ごとに 1 回 = 150 回/月

| 項目 | 計算 | 月額 |
|---|---|---|
| Workers AI Whisper | 1,500 分 × $0.000513 | 約 $0.77（無料枠内なら $0） |
| OpenAI gpt-4o-mini-transcribe | 1,500 × $0.003 | 約 $4.5 |
| OpenAI gpt-4o-transcribe | 1,500 × $0.006 | 約 $9 |
| 校正 Haiku 5.5 | 150 回 × (4,500 × $0.10 + 4,500 × $0.50) / 1M | 約 $0.4 |
| 校正 Sonnet 5.5 | 150 回 × (4,500 × $2 + 4,500 × $10) / 1M | 約 $8 |

おすすめの組み合わせ（Whisper ＋ Haiku 5.5）で、**月 約 $1 以下**。使う量が 10 倍でも約 $10。ただし、入力の長さが想定を超える、Haiku の校正の質が足りず Sonnet に上げる、のどちらかで数倍になる。

## この構成への入りやすさ（入口の案）

- 画像と同じ流れに合わせる
  - API: `POST /admin/w/{key}/transcribe`。画像の経路（`apps/api/src/images/routes.ts`、`wiki.route("/images", imageUploadRoutes)`）の隣に置く。本文を上限まで読む `readBodyUpTo`（`apps/api/src/images/upload.ts`）をそのまま使い、超えたら 413。種類は中身で見る。保存しない。ログに本文を出さない
  - バインディング: `wrangler.toml` に `[ai] binding = "AI"` を足し、`Deps` に任意の項目として渡す（無ければ 503。画像の `images?` と同じ書き方）
  - 回数の制限: `rate-limit.ts` は接続元ごと。人ごと・wiki ごとの制限が要るなら、`[[ratelimits]]` のキーを `user.id` にする別の制限が要る（今ある仕組みの延長でできる）
  - エディタ: `imageUpload.ts` の「処理中の目印 → 結果を入れる → 失敗の理由を出す」の流れに合わせる。結果はカーソルの位置に入り、自動保存（`useDraftAutosave.ts`）に乗る
- 外へ出る通信が今は無い（README）。Workers AI は同じ Cloudflare の中なので、この「初めて」を避けられる。校正を足すときに初めて外へ出る
- 録音の形式（`MediaRecorder` が出す webm / mp4）のうち、Whisper が受けられるものは確かめられなかった。実装の最初に、Chrome と iOS Safari で実際に通す

## 未決のこと（判断をください）

### 1. 方式
- A（おすすめ）: B（Workers AI Whisper）から始める — 月 $1 以下、鍵が要らない、音声が Cloudflare の外へ出ない
- B: A（Web Speech API）から始める — 費用 0。Firefox・Edge で使えない人が出る。Chrome では音声が Google へ送られる
- C: B' （OpenAI）— 精度が上がる可能性はあるが、月 $4.5〜9 と新しい事業者が増える。日本語の精度を比べてから決めるなら、この案

### 2. 校正（C）をするか、するなら何を直すか
- A（おすすめ）: 第1段では校正しない。使ってみて必要と分かったら足す — 書き起こしだけで足りるかを先に見られる
- B: 句読点・言い直しの除去だけ校正する — 言っていないことが入りにくい
- C: 言い回しまで直す — 読みやすいが、元の発言からずれやすい
- 直す前の文を残して選べるようにするか（B・C を選ぶなら残すのをおすすめ）

### 3. マイクのボタンの置き場所
- A（おすすめ）: 挿入メニュー（`InsertMenu`）— 画像と同じ「何かを入れる」入口で、カーソルの位置に入れる意味が分かりやすい
- B: スラッシュメニュー — キーボードのまま呼べる。録音中の状態表示との相性は悪い
- C: 編集画面のヘッダー — 常に見えるが、本文に入れるものという関係が薄れる
- D: 選択範囲のバブルメニュー — 選んだ文を言い直す使い方になる。第1段には広い

### 4. 使える人
- A（おすすめ）: wiki のメンバー全員 — 画像のアップロードと同じ。上限は人ごとに持つ
- B: 管理者だけ — 費用の事故が起きにくい

### 5. 費用の上限の決め方
- 1回の長さ（例: 3 分まで）と、人ごとの 1 日の回数の併用をおすすめ。月の予算の上限は、Workers AI は無料枠を超えたら課金なので、Cloudflare 側の使用量の通知で見る（確かめられなかった: 上限で止める設定があるか）

### 6. 音声が外へ送られることの伝え方
- A（おすすめ）: 録音を始める最初の 1 回だけ、「音声は書き起こしのために Cloudflare のサービスへ送り、保存しない」と出し、同意してから使えるようにする
- B: ボタンの横のヘルプ（HelpTip）に書くだけにする
- 校正を足すときは、書き起こした文字が Anthropic へ送られることも書き足す

## 確かめられなかったこと

- 日本語の書き起こしの精度（Whisper 系・gpt-4o 系とも）。公式ページに数字が無かった。**実装の前に、手元の実際の日本語の音声で比べる**
- Workers AI の Whisper の、音声の大きさ・長さの上限と、受けられる録音の形式
- 書き起こしの遅延（秒）。測っていない
- Web Speech API の、ブラウザごとの日本語の対応と、`processLocally` の対応状況（MDN の表が取れなかった）
- Claude が音声を直接受けられるか、の 2026 年 5 月以降の状況
- 校正の入出力のトークン数（見積もりのまま）と、Haiku 5.5 の校正の質
- 無料枠を超えたときに止める設定があるか
